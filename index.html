About

Perfectionist, pragmatist, engineer.

I think in JavaScript. Not in one framework or another, in the language itself: the event loop, the rendering pipeline, all the quiet machinery underneath. I like knowing exactly what my code is doing, and why. When I’ve done my job well, nobody has to think about it. Things just work, quietly, and keep working.

AI · Frontend systems

From Prompt to Product

[ led end to end ]

Plain English in, a live working product out. I architected the pipeline in between: it vets the request, hands the model exactly the context it needs, checks everything that comes back, and recovers cleanly when a generation goes wrong.

Vanilla JS · Architecture

A State Engine, From Scratch

[ zero dependencies ]

A reactive state system written in vanilla JavaScript, from first principles: subscriptions, derived values, its own update lifecycle. Components re-render only when something they depend on changes, so it stayed fast as the app grew.

React · Integration

A React Editor in a Non-React World

[ one adapter, any host ]

A modern React editor had to live inside a legacy codebase that shares none of its assumptions. I designed the bridge: the whole app packaged like a third-party library. Initialize it, hand it data, and it runs, there or anywhere else.

Platform · Systems

An Incremental Framework Upgrade

[ zero downtime ]

The platform was still shipping daily on Vue 1, with Vue 3 already out in the world. Instead of a rewrite, I taught the old codebase the new versions’ habits piece by piece, aligning every pattern to stay valid two upgrades ahead. When the move came, it was quiet. Nothing major broke.
